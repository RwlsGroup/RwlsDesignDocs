# Mobile Application

The Right Weigh mobile application supports **Android and iOS** and communicates with compatible devices over **Bluetooth Low Energy (BLE)**.

## Scale Detail and firmware updates

Each time the user opens **Scale Detail**, the app scans for the device and reads its information, including its firmware version. The app compares that version with the firmware version available online. If a compatible update is available, the app displays a firmware update link. The user can select it to download the firmware and start the OTA update.

OTA support is under development and being introduced progressively from **2026**. Availability depends on the device and firmware version.
