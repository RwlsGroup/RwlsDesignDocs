# Display and Input

Display and input are product-specific. The 202 uses a color display with touch input; the 201 uses a seven-segment display and mechanical buttons.

## Display responsibilities

The application presents measurements, device state, warnings, and setup workflows. Document the display controller and MCU interface, refresh behavior, brightness control, startup screen, measurement units, and behavior when sensor data is unavailable.

## Input responsibilities

Touch or button events select screens and invoke supported actions. Document event mapping, debouncing/filtering, long-press behavior, input lockout, and the user feedback shown for rejected actions. Keep safety-relevant thresholds and calibration authorization rules in the product requirements.

See the product hardware pages for known interface differences. Exact controller and pin-level details must come from each approved schematic and firmware configuration.
