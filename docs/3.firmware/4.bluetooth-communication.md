# Bluetooth Communication

The BLE module provides the radio connection to the mobile application, while the main MCU owns gauge sensing and product behavior. The MCU-to-module link is UART. The module part differs by product: BGM220P on 201 and BGM220S on 202.

## Documented protocol areas

For each compatible firmware and mobile-app release, maintain the BLE service/characteristic UUIDs, roles and permissions, advertising identity, connection behavior, payload encoding, command/response framing, notification rules, and error/status codes. Record the UART-side framing between the MCU and BLE module separately from the over-the-air GATT protocol.

The 202 application source includes SMP-style image-upload packet parsing for an OTA path. Confirm the active BLE characteristic, complete response path, and production support in the corresponding module and mobile-app versions before treating this as an available user feature.

## Compatibility

Track the compatible combinations of product hardware, MCU application, BLE module firmware, and mobile application. Application OTA support does not by itself imply that BLE module firmware is updated.
