# Pressure Calculation and Calibration

## Pressure acquisition

On the 202 target, firmware reads four MS5837 pressure sensors and a separate MS5637 barometric sensor. Sensor drivers perform the device-specific conversion and compensation; application code retains each sensor's identity and units for downstream calculations.

## Calculation documentation

For each released algorithm, record:

- raw sensor quantities and units;
- temperature and barometric compensation inputs;
- conversion equations and constants;
- filtering, plausibility limits, and invalid-data handling;
- mapping from sensor channels to physical axle/vehicle positions;
- output units, rounding, and display/mobile presentation.

Do not treat the sensor pressure reading as a calibrated vehicle weight without the product-specific calibration and conversion model.

## Calibration data

Calibration workflow and stored values are product-specific. Document the authorized calibration procedure, required reference loads, acceptance limits, storage location, data version, and reset/recovery behavior. The 202 source includes calibration data access to QSPI flash; verify the exact layout and persistence rules for the target build.
